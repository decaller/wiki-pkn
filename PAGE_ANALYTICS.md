# Page Analytics Implementation: Quartz

Quartz provides out-of-the-box configuration support for multiple third-party analytics providers directly inside `quartz.config.yaml`, eliminating the need to manually inject tracking code into layout templates.

---

### Built-In Analytics Integrations

Quartz natively handles initialization scripts for several standard platforms through configuration parameters:

* **Google Analytics:** Enabled via `{ provider: 'google', tagId: 'G-XXXXXXXXXX' }`.
* **Privacy-Focused Analytics:** Native support for lightweight alternatives including **Cabin**, **Tinylytics**, and **Matomo**.
* **Session Replay & Product Analytics:** Direct integration blocks for **PostHog** and **Microsoft Clarity**.
* **Infrastructure Analytics:** Native hook for **Vercel Web Analytics** when hosted on the platform.

---

### Single-Page Application (SPA) Tracking Handling

* **The Challenge:** Because Quartz defaults to client-side SPA routing (`enableSPA: true`) to make page transitions instantaneous without full browser reloads, standard out-of-the-box tracking scripts often register only the initial landing page view and miss subsequent internal link clicks.
* **The Resolution:** Quartz’s core integration automatically hooks into its client-side routing lifecycle, ensuring internal transitions across a digital garden or documentation site register accurately as separate page views.

---

### Improvements & Advanced Gaps Needed

* **Granular Interaction Tracking:** Built-in providers only track macro metrics like page views, bounce rates, and session durations. Capturing micro-interactions—such as clicks on the interactive link graph, full-text search queries, or outbound link clicks—requires custom event-tracking code manually wired into individual component scripts.
* **Privacy Compliance & Consent Banners:** Static sites generated by Quartz do not include native GDPR or cookie consent management frameworks. Deploying trackers like Google Analytics or Microsoft Clarity requires manually integrating a client-side consent manager to block tracking cookies until user permission is granted in regulated regions.
