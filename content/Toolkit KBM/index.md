> [!SUMMARY] Ringkasan Eksekutif (TL;DR Lead Section)
> **Hakikat Portal:** **Toolkit KBM Guru Karakter Nabawiyah** adalah pusat perkakas operasional siap pakai untuk membebaskan pendidik dari jeratan beban administratif formalitas. Dokumen ini mengalihkan energi guru menuju hadirnya kehangatan tatap muka dan pendampingan fitrah santri (*Tarbiyah bil-Mu'ayasyah*).
> * **Prinsip Utama:** Setiap instrumen mengharamkan reduksi akhlaq menjadi angka. Format kurikulum memadukan tiga pilar (Iman, Adab, Ilmu) dan menegakkan pemulihan adab berbasis fitrah (*Restorative Ta'dib*).
> * **Orientasi Terapan:** Seluruh format berformat markdown bersih yang siap disalin (*copy-to-clipboard*). Dokumen dapat dicetak pada kertas A4 atau diolah bersama kecerdasan buatan melalui bank prompt terstruktur.

## 1. Peta Jalan Pendidik: Dari Beban Administratif Menuju Sentuhan Fitrah

Dalam sistem pendidikan konvensional, waktu dan energi guru kerap habis tersita oleh tumpukan dokumen administratif. Guru disibukkan menyusun RPP tebal yang jarang dibuka saat mengajar. Evaluasi belajar sering kali mereduksi keimanan santri menjadi skor angka statistik hampa. Manhaj Pendidikan Karakter Nabawiyah (PKN) merombak total kebiasaan administratif tersebut.

Sesuai aturan tata kelola konten pada *User Journey Tahap 4*, berkas pada direktori ini dipisahkan dari teori epistemologi makro. Guru yang memasuki ruang kelas atau musyrif di asrama membutuhkan instrumen kerja yang ringkas. Setiap dokumen di bawah ini terbukti aplikatif di lapangan dan berakar pada Sunnah Nabawiyah.

```
                           ALUR IMPLEMENTASI KBM FITRAH
┌─────────────────────────────────────────────────────────────────────────────────┐
│ 1. PERENCANAAN RINGKAS        2. EKSEKUSI REALITAS         3. PEMANTAUAN TUMBUH │
│ ┌──────────────────────┐     ┌──────────────────────┐     ┌───────────────────┐ │
│ │ RPP 1 Lembar Nabawi  │ ──> │ KBM Pembelajaran     │ ──> │ Rubrik Observasi  │ │
│ │ (Iman, Adab, Ilmu)   │     │ Alamiah (2 Pintu)    │     │ 19 Butir (BT-MM)  │ │
│ └──────────────────────┘     └──────────────────────┘     └───────────────────┘ │
│                                         │                                       │
│                                         ▼                                       │
│                              ┌──────────────────────┐                           │
│                              │ Respon Masalah Adab: │                           │
│                              │ Lembar Dialog Batin  │                           │
│                              │ (Restorative Ta'dib) │                           │
│                              └──────────────────────┘                           │
└─────────────────────────────────────────────────────────────────────────────────┘
```

Perubahan mendasar yang dihadirkan oleh Toolkit KBM mencakup tiga ranah penting:
1. **Penyatuan Tiga Ranah Jiwa:** Memadukan *Nafsul Muthmainnah* (afeksi tauhid), *Nafsul Lawwamah* (nalar kognisi syar'i), serta *Nafsul Ammarah terdidik* (amal motorik nyata).
2. **Penghapusan Angka Semu:** Meniadakan vonis angka kaku pada penilaian karakter. Skor angka digantikan oleh deskripsi jenjang kematangan kualitatif (*Belum Terlihat*, *Mulai Tumbuh*, *Berkembang Konsisten*, dan *Membudaya Menjadi Teladan*).
3. **Pemberdayaan Bersama AI:** Menyediakan perintah terstruktur agar guru dapat memanfaatkan asisten kecerdasan buatan tanpa kehilangan kemurnian manhaj nabawi.

## 3. Matriks Peran Pengguna: Siapa Menggunakan Apa?

Penerapan instrumen di lingkungan madrasah dan pesantren diatur berdasarkan amanah pendidik:

### 3.1 Guru Mata Pelajaran dan Guru Kelas
* **Instrumen Wajib:** Menggunakan [[Template RPP Karakter Nabawiyah 1 Lembar]] sebelum mengajar di kelas.
* **Instrumen Pendukung:** Memanfaatkan [[Formulir Desain Proyek Pembelajaran Alamiah]] untuk unit karya santri. Guru dapat memakai [[Bank Prompt AI Guru KBM]] untuk menyusun apersepsi tadabbur kauniyah.
* **Tanggung Jawab:** Memastikan setiap topik pelajaran (Matematika, IPA, Bahasa, Fiqh) selalu berakar pada tauhid dan melatih adab santri.

### 3.2 Musyrif Asrama dan Pengasuh Pondok Pesantren
* **Instrumen Wajib:** Mengisi [[Instrumen Observasi Pertumbuhan Karakter 19 Butir]] guna memantau dinamika ibadah harian santri.
* **Instrumen Respon:** Menggunakan [[Lembar Dialog Evaluasi Hati Guru-Santri]] saat timbul perselisihan antarsantri atau pelanggaran tata tertib asrama.
* **Tanggung Jawab:** Menjadi teladan (*uswah*) hidup selama 24 jam penuh dan menjaga iklim ukhuwah asrama agar tetap tenang.

### 3.3 Konselor Adab dan Guru Bimbingan Santri
* **Instrumen Utama:** Menjadikan [[Lembar Dialog Evaluasi Hati Guru-Santri]] sebagai protokol baku penanganan santri tanpa kekerasan dan tanpa pelabelan negatif.
* **Instrumen Analisis:** Menelaah [[Instrumen Observasi Pertumbuhan Karakter 19 Butir]] untuk membaca grafik perkembangan jiwa anak.
* **Tanggung Jawab:** Menuntun santri mengenali bisikan nafsu dan menghantarkannya menuju kesadaran batin (*Nafsul Muthmainnah*).

### 3.4 Pimpinan Sekolah dan Tim Pengembang Kurikulum
* **Instrumen Utama:** Menetapkan [[Template RPP Karakter Nabawiyah 1 Lembar]] dan [[Formulir Desain Proyek Pembelajaran Alamiah]] sebagai standar operasional mutu pengajaran.
* **Instrumen Pemantauan:** Menghimpun laporan naratif dari [[Instrumen Observasi Pertumbuhan Karakter 19 Butir]] untuk pelaporan perkembangan santri kepada wali murid.
* **Tanggung Jawab:** Melindungi para guru dari beban administrasi berlebih serta memfasilitasi sarana belajar alamiah di luar kelas.

## 4. Panduan Transisi Lembaga: Tiga Tahap Adopsi Praktis

Sekolah Islam, madrasah, kuttab, maupun pesantren yang bertransisi menuju kurikulum berbasis fitrah disarankan menempuh tahapan berikut:

```
BULAN 1: PENYATUAN HATI & BAHASA
├── Menghapus tradisi pemeringkatan angka pada mata pelajaran adab dan karakter.
├── Mensosialisasikan skala rubrik 4 jenjang (BT, MT, BK, MM) kepada seluruh dewan guru.
└── Guru mulai menggunakan Lembar Dialog Batin saat menangani santri berselisih.

BULAN 2: INTEGRASI PEMBELAJARAN
├── Seluruh guru mapel beralih menggunakan RPP Karakter 1 Lembar.
├── Membiasakan alokasi 15% waktu pembuka untuk koneksi batin (Bahasa Hati).
└── Mengintegrasikan 1 ayat Al-Qur'an dan 1 hadits shahih pada setiap topik bahasan.

BULAN 3: EKSPANSI REALITAS ALAMIAH
├── Meluncurkan minimal satu Proyek Pembelajaran Alamiah di setiap jenjang kelas.
├── Mendistribusikan peran santri berdasarkan potensi fitrah bakat TB-40.
└── Menyusun rapor naratif santri berbasis himpunan catatan anekdot harian.
```

Untuk memperdalam landasan filosofis di balik setiap instrumen, para pendidik disarankan menelaah rujukan utama berikut:

* **Konsep Pemetaan Bakat Syar'i:** [[Panduan Asesmen dan Observasi TB40|Tafsir Bakat 40]] — Panduan 40 pilar karakter nabawiyah dan fitrah bakat santri.
